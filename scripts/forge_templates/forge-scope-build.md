## Step 1 — 계약 + 테스트 (RED)

목표: 계약(인터페이스/DTO)과 실패하는 단위 테스트를 작성한다. 구현은 아직 없음 → 테스트는 올바른 이유로 실패해야 함.

- [ ] **계약**: _(TASK §12 외부계약/데이터구조 기반 — 인터페이스·DTO·시그니처)_
- [ ] **단위 테스트**: _(TASK §9.1 TS 행 기반, §9 AC 검증. 전부 단위 테스트)_
- [ ] **커밋**: `test({docName}): 계약 + RED 테스트`

## Step 2 — 구현 (GREEN)

목표: Step 1 테스트를 통과시키는 최소 구현.

- [ ] **구현체**: _(TASK §8 작업 단계 기반. 테스트 통과 최소 코드, 범위 밖 리팩토링 금지)_
- [ ] **커밋**: `feat({docName}): 구현`

## Step 3 — 빌드 + 유닛테스트 통과

목표: 대상 프로젝트만 빌드·테스트하고 통과까지 개선한다.

- [ ] `dotnet build <타겟>.csproj`  ← **솔루션 금지**
- [ ] `dotnet test <타겟>.csproj`
- [ ] 실패 시 통과까지 개선
- [ ] **커밋**: `fix({docName}): 빌드/테스트 통과`
