# ARD-TEMPLATE — Redirect

> ⚠ **REDIRECT TEMPLATE** — 0.3 신규 결정 문서는 App별 ARD 템플릿을 사용한다.

0.3 문서 체계의 결정 문서는 전역 단일 누적 파일이 아니라 App별 개별 ARD 파일이다.

신규 결정 작성 시 아래 템플릿을 사용한다.

- 원본: `_templates/App/ARD/APP-ARD-001-TEMPLATE.md`
- 결과: `Docs/{App}/ARD/{App}-ARD-{NNN}.md`
- 인덱스: `Docs/{App}/{App}-ARD-CATALOG.md`

작성 순서는 [`DOCUMENT_GUIDE §2`](DOCUMENT_GUIDE.md#2-작성-순서) 의 "신규 결정 등재" 절을 따른다.
