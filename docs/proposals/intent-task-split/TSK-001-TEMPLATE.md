# TSK-{NNN} — {작업 제목}

> ⚠ **TEMPLATE** — 본 파일은 Task 문서 템플릿이다. 복사한 뒤 모든 `{...}` placeholder 를 실제 값으로 채우거나 해당 줄을 삭제하고, **이 경고 블록을 삭제**한다. 결과 파일은 레포 루트 `.task/TSK-{NNN}.md` 이고 문서 ID 는 `TSK-{NNN}` 이다 (`NNN` = 3자리 0패딩, 레포 전체에서 하나의 번호열). `.task/` 는 커밋한다 — gitignore 대상이 아니다.
>
> **Task 는 작업 계약서**: 이번 작업이 Intent(기능 문서)의 어느 항목을 어떻게 바꾸는지, 무엇이 되면 완료인지를 정한다. App 하나에 묶이지 않는다 — 여러 App 의 Intent 를 함께 바꾸는 작업도 Task 하나다. 기능의 동작(FR · Edge · Error)은 Intent 에 있고, Scope 는 바뀐 항목의 사본이다. **내부 코드 이름(클래스 · 인터페이스 · 메서드 · 함수 · 속성 · 필드 · 변수 · 네임스페이스 · 파일)은 어디에도 쓰지 않는다** — 개발 세션 몫이다. 밖에서 보이는 이름(API 경로 · 요청/응답 필드 · 설정 키 · 오류/상태 코드 · 화면 문구)은 쓴다. 이름 규칙 상세는 DOCUMENT_GUIDE §1.4.
